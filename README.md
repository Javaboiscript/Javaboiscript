## 🚀 Featured Projects

### [Vision Spectrum](https://github.com/Javaboiscript/Vision)
Extracts structured information from purchase orders, invoices, bills, receipts, and PDFs using open-source vision-language models.

`Python` `Hugging Face` `Qwen2.5-VL` `Document AI`

### [AI Multi-Agent Courtroom](https://github.com/Javaboiscript/Multi-Agent-CourtRoom)
A courtroom simulation with legal research, adversarial arguments, parallel judge agents, and structured verdicts.

`Python` `LangGraph` `LangChain` `ChromaDB` `Streamlit`

### [Hybrid GraphRAG Insurance Claim Assistant](https://github.com/Javaboiscript/RAG_based_InsuranceClaimAssistant)
Answers insurance-policy questions using hybrid vector and graph retrieval, with structured, traceable claim decisions.

`Python` `FastAPI` `Streamlit` `Neo4j` `Gemini` `Hugging Face`

### [Text-to-SQL Table Retrieval](https://github.com/Javaboiscript/Force_Laxman)
Finds relevant database tables from natural-language questions with hybrid keyword and semantic retrieval, reranking, and join-path filtering.

`Python` `BM25` `Sentence Transformers` `Semantic Search`

### [Sales Forecasting System](https://github.com/Javaboiscript/Sales_forecasting_thingy)
Compares forecasting approaches and serves weekly sales predictions through an API.

`Python` `XGBoost` `SARIMA` `Prophet` `LSTM` `FastAPI`

### [Metal Crack Analysis & Segmentation](https://github.com/Javaboiscript/Metal_Crack_DetectionAndMeasurement)
Segments cracks in metal surfaces and estimates their geometric measurements from images.

`Python` `PyTorch` `ResNet34` `U-Net` `OpenCV` `Streamlit`
